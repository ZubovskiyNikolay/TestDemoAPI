# TestDemoAPI

Учебный проект автотестов для API http://memesapi.course.qa-practice.com

## Стек
- Python 3.13, pytest, requests, allure-pytest

## Структура
- `endpoints/` — классы эндпоинтов
- `conftest.py` — фикстуры
- `tests/test_demoapi.py` — тесты

## Покрытие

### POST /authorize — авторизация
- успешная авторизация, в ответе есть `token` и `user` (200)
- без поля `name`, (400)
- `name` — число вместо строки, (400)

### GET /authorize/<token> — проверка токена
- валидный токен, (200)
- невалидный токен (404)

### POST /meme — создание мема
- создание с валидными данными, проверка структуры (200)
- без токена (401)
- без обязательного поля `text` (400)
- пустой payload (400)

### GET /meme — список мемов
- получение списка, созданный мем есть в списке (200)
- без токена (401)

### GET /meme/<id> — один мем
- получение по `id` (200)
- без токена (401)
- несуществующий `id` (404)

### PUT /meme/<id> — обновление мема
- обновление, все поля на месте, значения обновились (200)
- без токена (401)
- без обязательного поля (400)
- несуществующий `id` (404)

### DELETE /meme/<id> — удаление мема
- удаление + проверка через GET, что мем удалён (200 → 404)
- несуществующий `id` (404)
- без токена (401)


## Найденные проблемы API

### PUT /meme/<id> возвращает `id` строкой вместо числа

**Описание:**
В ответе на обновление мема поле "id" приходит как **строка**, тогда как во всех остальных эндпоинтах — как **число**.
